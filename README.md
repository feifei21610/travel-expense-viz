# 旅游花费可视化分析

一个基于 React + TypeScript + Recharts 的旅游支出数据可视化分析工具。

## 功能特色

- 📊 多维度数据可视化（饼图、柱状图）
- 📋 详细数据表格展示
- 🔍 支持数据筛选和排序
- 📱 响应式设计，适配各种设备
- 🎨 现代化 UI 设计

## 技术栈

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- Lucide React

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
